Resumo Executivo

O Infinity Tic-Tac-Toe é um motor de jogo multiplayer que utiliza uma arquitetura de Servidor Autoritativo para garantir a integridade das partidas. Desenvolvi uma solução onde toda a lógica de negócio — incluindo a mecânica de expiração de peças (modo infinito) e detecção de vitória — reside exclusivamente no Backend. Isso elimina vulnerabilidades de manipulação de estado no cliente e garante uma sincronização perfeita entre os jogadores via WebSockets.

Arquitetura Autorizativa e Type Safety

Diferente de implementações simples, utilizei TypeScript para definir contratos estritos entre cliente e servidor. O uso de interfaces e Enums garante que os pacotes de dados trafegados via Socket.io sejam validados em tempo de compilação, reduzindo drasticamente erros de runtime. No servidor, o estado de cada sala é isolado, permitindo escalabilidade horizontal para múltiplas partidas simultâneas.

Workflow de Validação: O servidor atua como a única fonte da verdade, processando a lógica antes do broadcast.
typescript – Engine de Movimento (Server-Side)
interface GameState {
    board: (string | null)[];
    history: Move[];
    turn: 'X' | 'O';
}

// Lógica central autoritativa: Valida e expira peças
function processMove(state: GameState, move: Move): GameState {
    const playerMoves = state.history.filter(m => m.symbol === move.symbol);
    
    if (playerMoves.length >= 3) {
        const oldest = playerMoves[0];
        state.board[oldest.position] = null; // Libera slot no board
        state.history = state.history.filter(m => m !== oldest);
    }
    
    state.board[move.position] = move.symbol;
    return state;
}

Sincronização de Baixa Latência e Gerenciamento de Salas

A comunicação em tempo real foi otimizada através do gerenciamento dinâmico de Rooms do Socket.io. O backend é responsável por orquestrar o matchmaking, criar identificadores únicos de sessão e gerenciar o ciclo de vida das conexões. Em caso de desconexão, o servidor limpa o estado da memória, evitando memory leaks.

Broadcast Seletivo: Garantindo que apenas os jogadores da mesma sala recebam as atualizações de estado.
typescript – Controller de Eventos (WebSocket)
socket.on('make_move', ({ position, roomId }) => {
    const game = roomManager.getGame(roomId);
    
    // Early return: Segurança contra jogadas fora de turno ou salas inválidas
    if (!game || game.turn !== socket.id) return;

    const updatedState = game.executeMove(position);
    io.to(roomId).emit('update_game', updatedState);
});

Engenharia de Backend Aplicada

  • Strict Typing: Modelagem de dados com TypeScript para garantir consistência no tráfego WebSocket.
  • Stateful Server: Gerenciamento eficiente de estados em memória para partidas multiplayer.
  • Race Condition Prevention: Lógica de validação sequencial para evitar movimentos duplicados no mesmo milissegundo.
  • Modular Strategy: Separação de regras (Classic vs Infinity) usando o Design Pattern Strategy.
