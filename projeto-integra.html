Resumo Executivo

O Integra é uma plataforma digital que promove a acessibilidade comunicacional de pessoas surdas no ambiente educacional. Composto pelos módulos Mãos que Falam (tradução de fala para Libras) e Além das Mãos (comunicação bidirecional e multilíngue), o sistema combina reconhecimento de voz, processamento de áudio, tradução automática e animação 3D para eliminar barreiras entre surdos, ouvintes e estrangeiros.

Pipeline de Áudio: Engenharia de Baixa Latência

Um dos maiores desafios técnicos foi garantir a sincronia entre a fala e a sinalização do avatar. Para isso, implementei um pipeline de processamento no cliente que utiliza a Web Audio API para preparar o sinal antes do envio via WebSocket.

Tratamento de Sinal Digital (DSP)

A precisão dos motores de reconhecimento (Vosk/Google) depende da qualidade do áudio. Aplicamos filtros em tempo real:

  • High-pass (300 Hz): Remove ruídos de baixa frequência (ventiladores, vibrações).
  • Notch (60 Hz): Filtra interferências elétricas da rede.
  • Compressor Dinâmico: Normaliza o volume para evitar distorções (clipping).
Figura 2: Cadeia de filtros digitais aplicada no front-end
javascript – Configuração de Filtros Digitais
const highpass = audioContext.createBiquadFilter();
highpass.type = 'highpass';
highpass.frequency.value = 300;

const notch = audioContext.createBiquadFilter();
notch.type = 'notch';
notch.frequency.value = 60;

const compressor = audioContext.createDynamicsCompressor();
compressor.threshold.value = -20;

// Microfone → Highpass → Notch → Compressor → Socket
source.connect(highpass).connect(notch).connect(compressor).connect(processor);

Arquitetura do Servidor: Gerenciamento de Buffers

No backend, gerenciei a conversão de taxas de amostragem em tempo real usando FFmpeg. O sistema adota uma estratégia de Prioridade de Metadados: o servidor aguarda as configurações do cliente antes de instanciar o pipeline, garantindo a integridade dos dados binários.

Figura 3: Lógica de inicialização e sincronização do servidor Node.js
javascript – Buffer de pré-inicialização
ws.on('message', (data) => {    
    if (isPipelineInitialized) {
        ffmpegInstance.pushAudio(data); // Streaming direto
        return;
    }

    if (Buffer.isBuffer(data)) {
        audioBuffer.push(data); // Armazena chunks até o handshake
        if (!isPipelineInitialized) initPipeline(FALLBACK_SAMPLE_RATE);
    }
});

Multilíngue e Renderização em Libras

O módulo Além das Mãos integra a Google Cloud Translate API, permitindo que falas em diferentes idiomas sejam convertidas primeiro em texto e depois sinalizadas pelo avatar 3D do VLibras. Esta etapa utiliza WebGL e Three.js para garantir que os sinais sejam renderizados com fluidez e precisão gramatical.
