Livro — Gestão de Vigilância Sanitária

Digitalização de Processos, Inteligência de Dados e Monitoramento de Denúncias

Node.js Sequelize ORM MySQL EJS Chart.js

Resumo Executivo

Desenvolvido para a Vigilância Sanitária de Andradina, o sistema Livro foi concebido para substituir completamente o modelo de registros físicos por uma plataforma digital centralizada. Fui responsável pelo ciclo completo: desde a análise de requisitos com os agentes municipais e arquitetura de dados até o deploy e manutenção em produção. A solução transformou o fluxo operacional, reduzindo o tempo médio de consulta de registros de 5 minutos para apenas 10 segundos.

Arquitetura de Dados: Modelagem e Integridade

A transição do papel para o digital exigiu uma estrutura relacional rigorosa. Utilizei o Sequelize ORM para gerenciar as entidades e garantir a integridade referencial. Um ponto crítico foi a implementação de índices compostos para assegurar que cada combinação de ano e número de denúncia fosse única.

Fluxo de Registro: Garantindo a unicidade dos protocolos legais e integridade via Sequelize. (Clique para ampliar)
javascript – Definição do Modelo de Denúncia
const denunciation = connection.define('denunciations', {
    year: { type: sequelize.INTEGER, allowNull: false },
    number: { type: sequelize.INTEGER, allowNull: false },
    status: { type: sequelize.STRING },
    title: { type: sequelize.STRING, allowNull: false },
    description: { type: sequelize.TEXT, allowNull: false },
    user_id: { type: sequelize.INTEGER, allowNull: true }
}, {
    indexes: [{
        unique: true,
        fields: ['year', 'number'] // Unicidade de protocolo legal
    }]
});

Hooks e Automação de Dados

Implementação de Lifecycle Hooks para automação de slugs amigáveis.

javascript – Automação via Hooks (BeforeCreate)
const district = connection.define('districts', {
    name: { type: sequelize.STRING, allowNull: false },
    slug: { type: sequelize.STRING, allowNull: false, unique: true }
}, {
    hooks: {
        beforeCreate: (district) => {
            district.slug = slugify(district.name, { lower: true, strict: true });
        }
    }
});

Rastreabilidade e Logs de Auditoria

Implementei um módulo de Reports vinculado a cada denúncia para garantir a transparência governamental.

Fluxo de Evolução: Automação de logs de status e trilha de auditoria.
javascript – Modelo de Relatórios e Auditoria
const report = connection.define('reports', {
    description: { type: sequelize.TEXT },
    denunciation_id: { type: sequelize.INTEGER, allowNull: false },
    user_id: { type: sequelize.INTEGER, allowNull: false },
    type: { type: sequelize.INTEGER, allowNull: false } // Logs vs Pareceres
});

Infraestrutura e Implantação Local (Intranet)

O sistema opera na Intranet da Prefeitura sob um servidor Linux local com proxy reverso.

bash – Gestão de Processos e Servidor Web
# Gestão de Uptime com PM2
pm2 start bin/www --name "sistema-livro"

# Configuração de Proxy Reverso no Nginx Local
location / {
    proxy_pass http://localhost:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
