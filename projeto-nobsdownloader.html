O Problema

Plataformas de download de mídia costumam ser saturadas de anúncios abusivos, trackers e redirecionamentos maliciosos. O desafio era criar uma ferramenta que oferecesse uma interface limpa para extração de áudio e vídeo, lidando com a complexidade de bypass de bots e transcodificação de formatos em tempo real.

A Decisão: Orquestração de Processos Filhos

Para não sobrecarregar o loop de eventos do Node.js, implementei a orquestração do yt-dlp e FFmpeg via processos filhos (spawn). Isso permite o monitoramento direto da saída padrão (stdout), possibilitando o encerramento preventivo de tarefas que excedam limites de segurança.

Figura 1: Fluxo de extração: Da URL à entrega do binário processado.
javascript – Orquestração de Processos Filhos

const yt = spawn(YTDLP_PATH, ytArgs);

yt.stdout.on("data", (data) => {
    const output = data.toString();
    // Monitoramento preventivo de recursos: Bloqueio de arquivos > 1GiB
    if (output.includes("GiB")) {
        const sizeMatch = output.match(/(\d+\.\d+)GiB/);
        if (sizeMatch && parseFloat(sizeMatch[1]) >= 1.0) {
            exitReason = "LIMIT_EXCEEDED";
            process.platform === "win32" 
                ? exec(`taskkill /pid ${yt.pid} /f /t`) 
                : yt.kill("SIGKILL");
        }
    }
});

Gerenciamento de Segurança e Metadados

O sistema realiza um parsing rigoroso do endpoint /info para mapear resoluções e bitrates disponíveis, filtrando fluxos inválidos. Para garantir a estabilidade, utilizei diretórios temporários únicos que são limpos automaticamente após o processamento.

Figura 2: Pipeline de transcodificação de áudio via FFmpeg.
javascript – Filtragem Dinâmica de Formatos

json.formats.forEach(f => {
    const isVideo = f.vcodec !== "none" || f.video_ext !== "none";
    const height = f.height || parseInt(f.quality) || 0;

    if (isVideo && height > 0 && !videoMap.has(height)) {
        videoMap.set(height, { 
            format_id: f.format_id, 
            resolution: `${height}p`, 
            hasAudio: f.acodec !== "none" 
        });
    }
});
