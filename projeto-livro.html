Livro — Gestão de Vigilância Sanitária

Digitalização de Processos, Inteligência de Dados e Monitoramento de Denúncias

Node.js Sequelize ORM MySQL EJS Chart.js PM2 Nginx

O Problema

A Vigilância Sanitária de Andradina operava baseada em registros físicos, o que tornava a busca por históricos lenta e suscetível a perdas. O desafio era converter décadas de protocolos em um sistema digital que garantisse integridade legal e rapidez no atendimento ao cidadão.

Fui responsável pelo ciclo completo: desde o levantamento de requisitos com os agentes municipais até a arquitetura de dados e o deploy na infraestrutura local da prefeitura.

Arquitetura de Dados e Integridade

Para garantir que cada denúncia fosse única e rastreável, utilizei o Sequelize ORM com uma modelagem rigorosa. Implementei índices compostos para assegurar que a combinação de ano e número de protocolo fosse impossível de duplicar, mantendo a validade jurídica dos registros.

Fluxo de Registro: Garantindo a unicidade dos protocolos legais via DB Constraints.
typescript – Definição do Modelo de Denúncia

const Denunciation = connection.define('denunciations', {
    year: { type: Sequelize.INTEGER, allowNull: false },
    number: { type: Sequelize.INTEGER, allowNull: false },
    status: { type: Sequelize.STRING },
    title: { type: Sequelize.STRING, allowNull: false },
    description: { type: Sequelize.TEXT, allowNull: false }
}, {
    indexes: [{
        unique: true,
        fields: ['year', 'number'] // Unicidade de protocolo legal por exercício
    }]
});

Automação e Auditoria

Utilizei Lifecycle Hooks para automatizar a criação de slugs e metadados, além de um sistema de Reports que cria uma trilha de auditoria para cada alteração de status na denúncia.

Rastreabilidade: Cada interação gera um log vinculado ao agente responsável.

Infraestrutura e Deploy Local

Dada a natureza sensível dos dados, o sistema foi implantado na Intranet da Prefeitura em um servidor Linux com proxy reverso Nginx e gestão de uptime via PM2, garantindo que o serviço esteja sempre disponível para os fiscais.

bash – Gestão de Processos e Proxy Reverso

# Gestão de Uptime com PM2
pm2 start bin/www --name "sistema-livro" --watch

# Configuração Nginx Local
location / {
    proxy_pass http://localhost:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}

Resultado

A solução reduziu o tempo médio de consulta de registros de 5 minutos para apenas 10 segundos, permitindo que a equipe de vigilância foque na fiscalização de campo em vez de burocracia manual.
