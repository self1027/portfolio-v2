Resumo Executivo

O NoBSDownloader é uma ferramenta de extração de mídia desenvolvida para contornar a complexidade e os anúncios abusivos de sites de download. Utiliza yt-dlp e FFmpeg via processos filhos para entregar áudio e vídeo em alta fidelidade, com bypass de restrições via cookies dinâmicos e zero trackers.

Gerenciamento de Processos e Segurança

Para garantir a estabilidade do servidor, implementei um controle rigoroso de concorrência e limites de tamanho de arquivo. O sistema monitora a saída padrão (stdout) do processo para detectar em tempo real se o arquivo excede os limites de segurança.

Segurança e Controle Operacional

  • Taskkill/SIGKILL: Encerramento forçado de processos órfãos em abortos de usuário.
  • Job Isolation: Diretórios temporários únicos limpos automaticamente.
  • Bypass de Bot: Rotação de Cookies e User-Agents dinâmicos.
Figura 2: Pipeline de transcodificação de áudio via FFmpeg.
javascript – Orquestração de Processos Filhos
const yt = spawn(YTDLP_PATH, ytArgs);

yt.stdout.on("data", (data) => {
    const output = data.toString();
    // Monitoramento preventivo de tamanho em GiB
    if (output.includes("GiB")) {
        const sizeMatch = output.match(/(\d+\.\d+)GiB/);
        if (sizeMatch && parseFloat(sizeMatch[1]) >= 1.0) {
            exitReason = "LIMIT_EXCEEDED";
            process.platform === "win32" 
                ? exec(`taskkill /pid ${yt.pid} /f /t`) 
                : yt.kill("SIGKILL");
        }
    }
});

Arquitetura de Metadados Dinâmicos

O endpoint /info extrai metadados em formato JSON, mapeando resoluções de vídeo e bitrates de áudio disponíveis, filtrando fluxos inválidos.

Figura 3: Lógica de parsing e filtragem de formatos de mídia.
javascript – Filtragem de Formatos de Vídeo
json.formats.forEach(f => {
    const isVideo = f.vcodec !== "none" || f.video_ext !== "none";
    const height = f.height || parseInt(f.quality) || 0;

    if (isVideo && height > 0 && !videoMap.has(height)) {
        videoMap.set(height, { 
            format_id: f.format_id, 
            resolution: `${height}p`, 
            hasAudio: f.acodec !== "none" 
        });
    }
});
